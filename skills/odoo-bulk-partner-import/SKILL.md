# Odoo 거래처 대량 등록 (odoo-bulk-partner-import)

## 역할

엑셀/CSV/표 형태로 준 신규 거래처 목록을 **중복 체크 → 생성 → 결과 요약**
순서로 Odoo에 등록한다. 사람이 한 줄씩 손으로 입력하던 작업을 대체하는
스킬이므로, "한 건 실패해도 나머지는 계속 진행"하는 것이 핵심 원칙이다.

## 절차

1. **컬럼 매핑.** 입력 파일의 컬럼명이 아래와 다를 수 있다. 유사한 이름은
   자동으로 매핑한다 (예: "회사명"/"거래처명"/"업체명" → `name`).
   | 입력 컬럼(예시) | Odoo 필드 |
   |---|---|
   | 회사명 / 거래처명 / 업체명 | `name` (필수) |
   | 이메일 | `email` |
   | 전화 / 연락처 | `phone` |
   | 담당자 | (없으면 무시, 있으면 `name` 뒤에 괄호로 덧붙이거나 별도 `child_ids` 인물 레코드로 생성) |

2. **행 단위로 반복.** 각 행에 대해:
   ```
   a) mcp__odoo__search_records(model="res.partner", domain=[["name", "=", 행.name]])
      → 이미 있으면 이 행은 "스킵(중복)"으로 기록하고 다음 행으로
   b) 없으면 mcp__odoo__create_record(
        model="res.partner",
        values={"name": 행.name, "email": 행.email 또는 생략,
                 "phone": 행.phone 또는 생략, "is_company": true}
      )
      → 생성된 id를 기록
   c) 한 행이 실패(에러)해도 전체를 멈추지 않고 "실패" 목록에 사유와 함께
      기록한 뒤 다음 행으로 진행한다.
   ```

3. **결과 요약**을 반드시 표로 보여준다: 등록 N건(각 id 포함) / 스킵(중복)
   M건 / 실패 K건(사유 포함).

4. 실습/테스트 목적으로 만든 레코드는 이름에 "(실습용)" 같은 표시를 남기고,
   사용자가 정리를 요청하면 `mcp__odoo__delete_record`로 해당 id들만
   지운다 — 임의로 다른 레코드를 지우지 않는다.

## 안전장치

- **생성 전 반드시 `search_records`로 중복부터 확인한다.** 이걸 생략하면
  같은 이름의 회사가 중복 생성된다.
- 필수값(`name`)이 빈 행은 생성 시도 자체를 하지 않고 실패 목록에 바로
  올린다.
- 한 번에 처리할 행이 많으면(수십 건 이상) 진행 상황을 중간중간 알려준다.
